# Humans need not code

**Status:** seed
**Captured:** 2026-05-25

## The idea
New coding IDEs are becoming increasingly headless and easier to use — the act of "coding" is decoupling from the act of typing code. The headless turn (Claude Code, Cursor's background agents, Codex, etc.) means the IDE isn't where the human sits anymore. The interface to building software is collapsing toward intent.

## Working thesis (rough)
The IDE is no longer the workplace — it's the substrate. Humans don't need to code; they need to specify, judge, and steer. The skill ceiling moves from syntax to taste.
